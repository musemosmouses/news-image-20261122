A make.fun bounty entry: one image summing up the world's news of
Sunday 22 November 2026 — 51 real stories, all first reported on
22 November 2026 in some time zone.

`main.py` (Python 3.13, standard library only) draws the 1024×1024 PNG
to `$MAKEFUN_OUTPUT_DIR/entry.png`: a masthead naming the day, three
lead stories with drawn pictograms, a dense 48-story grid, a ten-moment
UTC timeline, and a footer date check with a source list. Deterministic:
two runs write byte-identical output.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
